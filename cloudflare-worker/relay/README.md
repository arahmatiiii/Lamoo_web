# رلهٔ آشپزخانهٔ مشترک لامو

یک سرویس کوچک روی Cloudflare که باعث می‌شود دو گوشی در یک خانه، یک انبار
مشترک ببینند.

**این رله نمی‌تواند چیزی از داده‌های شما بخواند.** هر چیزی که فرستاده می‌شود
روی گوشی خودتان رمزنگاری شده است؛ رله فقط بسته‌های رمزشده را نگه می‌دارد و
بین اعضای خانه پخش می‌کند. آدرس اتاق هم از روی کلید خانه ساخته می‌شود، نه
خود کلید — پس حتی آدرس هم کلید را لو نمی‌دهد.

## راه‌اندازی (یک‌بار، حدود ۵ دقیقه)

نیاز به Node روی کامپیوتر دارید. کافی است داخل همین پوشه اجرا کنید:

```bash
npx wrangler login     # یک‌بار، مرورگر باز می‌شود
npx wrangler deploy
```

در پایان آدرسی مثل زیر چاپ می‌شود:

```
https://lamoo-relay.<نام-شما>.workers.dev
```

همین آدرس را در اپ، در «تنظیمات ← آشپزخانهٔ مشترک ← آدرس رله» وارد کنید.

## بررسی سلامت

```bash
curl https://lamoo-relay.<نام-شما>.workers.dev/room/$(printf 'a%.0s' {1..64})
# {"records":[]}
```

اگر `{"error":"expected /room/<64-hex>"}` گرفتید یعنی آدرس درست است ولی
شناسهٔ اتاق را اشتباه داده‌اید — خود اپ این را درست پر می‌کند.

## هزینه

در پلن رایگان Cloudflare جا می‌شود. Durable Object برای یک خانواده در ماه
چند هزار درخواست بیشتر نمی‌گیرد.

## حذف

```bash
npx wrangler delete
```

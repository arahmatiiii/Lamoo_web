# سرور لامو

بک‌اند اپ: اکانت، آشپزخانهٔ مشترک سرورساید، و فید دوستان.

معماری کامل و دلیل هر انتخاب در `docs/SERVER.md` ریشهٔ مخزن است. این فایل فقط
راه‌اندازی است.

## اجرای محلی

```bash
cd server
npm install
npm test          # ۱۲۰ تست
npm run typecheck
npm run dev       # روی http://localhost:8787
```

Node نسخهٔ ۲۲٫۶ یا بالاتر لازم است — دیتابیس از `node:sqlite` داخل خود Node
استفاده می‌کند تا هیچ وابستگی نیتیوی برای کامپایل نماند.

## اجرا روی سرور

```bash
cp .env.example .env
nano .env          # حداقل DOMAIN را درست کن
docker compose up -d --build
docker compose logs -f api
curl https://<DOMAIN>/api/health
```

دامنه باید از قبل به IP سرور اشاره کند و پورت‌های ۸۰ و ۴۴۳ باز باشند؛ Caddy
گواهی TLS را خودش می‌گیرد و تمدید می‌کند.

بعد از اینکه خودت و خانواده و دوستانت ثبت‌نام کردید، `ALLOW_REGISTRATION=0` را
بگذار و `docker compose up -d` را دوباره بزن. سرور بسته می‌شود و غریبه‌ها
نمی‌توانند اکانت بسازند.

## نوتیفیکیشن (Web Push)

بدون کلید VAPID همه‌چیز کار می‌کند جز نوتیفیکیشن، و اپ هم همین را می‌گوید.
برای روشن کردنش یک‌بار کلید بساز و در `.env` بگذار:

```bash
docker compose run --rm api node -e "console.log(JSON.stringify(require('web-push').generateVAPIDKeys()))"
```

بعد `docker compose up -d` و در اپ: تنظیمات → آشپزخانهٔ مشترک → «نوتیفیکیشن یادآورها».
سرور هر دقیقه یادآورهای سررسیده و موادی که تا `EXPIRY_WARNING_DAYS` روز دیگر
تمام می‌شوند را پیدا می‌کند و به همهٔ اعضای خانه می‌فرستد — هر چیز فقط یک‌بار.

## بکاپ

همه‌چیز — کاربرها، انبار، دستورها، کارت‌ها و حتی تصویرها — در یک فایل SQLite است:

```bash
docker compose stop api
cp ./data/lamoo.db ~/lamoo-$(date +%F).db
docker compose start api
```

برای بکاپ بدون توقف سرویس:

```bash
docker compose exec api node -e "\
const {DatabaseSync}=require('node:sqlite');\
new DatabaseSync('/data/lamoo.db').exec(\"VACUUM INTO '/data/backup.db'\")"
cp ./data/backup.db ~/lamoo-$(date +%F).db
```

## نکات امنیتی که آگاهانه انتخاب شده‌اند

- **رمزها** با `scrypt` و نمک تصادفی ذخیره می‌شوند، نه خام و نه با هش ساده.
- **توکن‌ها** هش‌شده در دیتابیس‌اند؛ یک بکاپ دزدیده‌شده به‌تنهایی لاگین نیست.
- **کد دعوت خانوار** (۱۲ کاراکتر) به‌تنهایی عضویت می‌دهد، پس مثل رمز است.
  **کد دوستی** (۸ کاراکتر) هیچ دسترسی نمی‌دهد — فقط درخواست می‌سازد و صاحبش باید
  قبول کند. برای همین یکی بلند است و یکی کوتاه.
- **تصویر کارت‌ها** بدون احراز هویت سرو می‌شود، چون تگ `<img>` نمی‌تواند هدر
  Authorization بفرستد. شناسهٔ تصویر ۱۲۸ بیت تصادفی است، یعنی خودِ آدرس مجوز
  دسترسی است: هر کسی که آدرس را داشته باشد همان یک عکس را می‌بیند و نه چیز دیگری.
- **محدودیت نرخ** روی لاگین، ثبت‌نام و وارد کردن کدها فعال است، در حافظه. اگر
  روزی چند نمونه از سرور بالا آوردی، این باید به SQLite یا Redis منتقل شود.
- **برخلاف رلهٔ رمزشدهٔ Cloudflare، این سرور محتوای انبار را می‌خواند.** این
  معاوضهٔ آگاهانه‌ای است که فید دوستان و نوتیفیکیشن را ممکن می‌کند؛ توضیحش در
  `docs/SERVER.md` است. اگر ترجیح می‌دهی هیچ سروری نتواند بخواند، همان رلهٔ
  `cloudflare-worker/relay` سر جایش است و کار می‌کند.
